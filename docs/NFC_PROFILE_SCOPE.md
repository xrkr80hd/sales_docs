# NFC Profile Prototype — Locked Scope

## Product boundary

This prototype is a digital business card and NFC/RFID-linked profile platform. It is separate from the Walker NextDocs workflow and training product.

Do not import Walker NextDocs departments, job titles, training roles, F&I roles, management hierarchy, or document permissions into this prototype.

## Roles for the current prototype

The prototype has exactly two application roles:

1. `admin`
2. `user`

No additional roles, role builder, permission groups, job titles, or departmental access levels belong in the current prototype.

## Current ownership

- Admin account: `trav@xrkr80hd.studio`
- User/profile account: `xrkr80hd@gmail.com`

Trav may hold both administrative ownership and a user profile while the two responsibilities remain logically separate.

## Future dealership version

If the platform is later sold or licensed to a dealership, dealership-specific management capabilities may be designed then. That future possibility does not authorize adding those roles or permissions to the prototype now.

## Separate Walker NextDocs product

Walker NextDocs may later require granular roles, permissions, departments, consultants, sales managers, F&I, general managers, and configurable access. That authorization system must be planned and implemented separately from the NFC profile platform.

## Data and interface rule

Use real functional code and real data only. Never seed or display fabricated people, vehicles, reviews, leads, posts, metrics, or other mock content. When a feature has no real data or working backend, show a clearly labeled empty state or keep the feature hidden.
