Theme research:
- Toyota official palette: Red #EB0A1E, white, black, gray. https://brand.toyota.com/guidelines/visual/brand-colors
- Honda official palette: Honda Red #CC0000, white, black, gray. https://global.honda/en/brandplaybook/creativeinspiration/
- Kia: Midnight Black #05141F, Polar White; Live Red #EA0029 is an optional accent. https://www.kia.com/nmc/en/discover-kia/ask/what-is-the-meaning-behind-Kias-brand-color.html and current US stylesheets.
- BMW: blue/white with gray/black, supported by official brand-history reporting and current website/logo. The app blue is a screen adaptation. https://www.press.bmwgroup.com/latin-america-caribbean/article/detail/T0452127EN/
- Mercedes-Benz: black/silver with blue digital actions; current MBUSA CSS uses #0078D6. https://www.mbusa.com/en/home
- Mazda: current US CSS uses black #101010, white/light-gray, burgundy #910A2D. https://www.mazdausa.com/assets/styles/styles.min.css?v=1.20.6.0
- GMC: current US core CSS uses black/gray/chrome and red #E60000. https://www.gmc.com/
- CDJR is a multi-brand dealership, not a single manufacturer palette. The requested Walker red/black/gray combination is retained, with the supplied Walker mark until an organization icon is uploaded. Individual manufacturers retain distinct identities: https://media.fcanorthamerica.com/image-gallery.do?imageGalleryId=383&method=view

These are application palettes adapted to readable screen controls, not claims that every chosen background/hex is a formal corporate specification. Walker dealership sites rejected asset retrieval with HTTP 403; no unverified local-dealer palette was substituted.
